## Key Decisions
- Used `vi.mock('fs', ...)` string literal (not `import('node:fs')` dynamic import) because vitest v2.1.9 does not normalize the `node:` scheme to match `import fs from 'fs'` in source code — this was causing all fs-dependent test files to silently use the real filesystem instead of the mock
- Mock factory variables (`mem`, `mockImpl`) are returned from `vi.hoisted()` as a destructured object so they're initialized before the hoisted `vi.mock` call runs — prevents `ReferenceError: Cannot access before initialization`
- Deleted real `defects.json` from disk to prevent test bleed from real filesystem reads
